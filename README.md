# سافاير — Sapphire

تطبيق جوال + Galaxy Watch7: تمرين مشي يكتشف الجري تلقائياً بنفس الجلسة، مدرب صوتي عربي، خريطة مسار ملوّنة، ومزامنة مع Samsung Health عبر Health Connect.

## التشغيل

1. افتح مجلد `Khutwa` في Android Studio ← **Open** وخله يسوي Gradle Sync.
   لو طلب يحدّث AGP أو نسخ المكتبات، وافق.
2. **الجوال:** وصّل الجوال بـ USB (مفعّل USB debugging) ← اختر `mobile` ← Run.
3. **الساعة:** فعّل Developer options في الساعة ← Wireless debugging.
   في Android Studio: **Device Manager ← Pair using Wi-Fi** أو من الطرفية:
   ```
   adb pair IP:PORT
   adb connect IP:PORT
   ```
   بعدها اختر `wear` ← Run.
4. **Samsung Health:** في التطبيق اضغط "اربط مع Samsung Health" ووافق على الصلاحيات.
   وفي Samsung Health نفسه: الإعدادات ← Health Connect ← فعّل المزامنة.

> لازم التطبيقين ينبنون بنفس مفتاح التوقيع (debug نفسه يكفي) عشان الساعة تكلم الجوال.

## الواجهة

- **الرئيسية:** خطوات اليوم، ونبض القلب، والنوم، ودقائق التمرين، وعدد تمارين الأسبوع والشهر، وتمارين اليوم.
  الأرقام كلها تنقرأ من Health Connect، وSamsung Health هو اللي يكتبها هناك.
- **الثيم:** يتغير حسب الجهاز، فاتح أو داكن.
- **أنواع التمرين:** مشي، جري، كرة قدم.
  كرة القدم ما فيها تنبيهات مشي وجري، وتحسب السبرنتات (فوق 18 كم/س لمدة ثانية ونص) وأعلى سرعة.
- **الساعة:** تاخذ أرقام اليوم من الجوال تلقائياً.
- **الخطوط:** Readex Pro وDoto موجودة داخل المشروع في `res/font`.

## كيف يشتغل

| الجزء | الملف |
|---|---|
| اكتشاف مشي/جري | `shared/.../GaitClassifier.kt` |
| تسجيل المسار والمقاطع والكيلومترات | `shared/.../WorkoutRecorder.kt` |
| عبارات المدرب الصوتي | `shared/.../ArabicCoach.kt` |
| تمرين الساعة (Health Services) | `wear/.../ExerciseService.kt` |
| تمرين الجوال (GPS + خطوات) | `mobile/.../Services.kt` |
| الكتابة في Health Connect | `mobile/.../Data.kt` ← `HealthSync` |
| الخريطة | `mobile/.../RouteMap.kt` |

- **الاكتشاف** يعتمد على السرعة أولاً، والـ cadence إشارة مساعدة بس.
  - يتحول لجري إذا السرعة ≥ 7.4 كم/س لمدة 8 ثواني.
  - يرجع مشي إذا نزلت تحت 6.5 كم/س لمدة 12 ثانية.
  - تقدر تعدل القيم في `GaitClassifier`.
- **الصوت:** إذا الساعة ما فيها صوت عربي، تحوّل الكلام للجوال وينطق منه (أو من السماعة اللي على الجوال).
- **الساعة ← الجوال:** بعد ما تنهي التمرين يتخزن في الساعة وينرسل عبر Data Layer، ويوصل حتى لو الجوال كان بعيد وقت التمرين.
- **أثناء التمرين:** اضغط على رقم الوتيرة (بالساعة أو الجوال) وينطق لك المسافة والوتيرة والنبض.
